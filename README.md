## 🚀 Run Locally

Clone this repository:

```bash
https://github.com/760lakshmi-create/lakshmi-portfolio
```

Navigate to the project:

```bash
cd lakshmi-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
