## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/760lakshmi-create/lakshmi-portfolio.git
```

### 2. Navigate to the project

```bash
cd lakshmi-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```
